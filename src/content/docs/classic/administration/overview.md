The smart client is a Windows application installed on each PC (or run from a shared install). Most administration happens on the server and is the same whichever client people use, but a handful of jobs only exist because there's a desktop client: installing and updating it, its local configuration file, its local cache, and the errors that come from a damaged profile.

| Page | What it covers |
|---|---|
| [Installing the smart client](/classic/administration/installing-the-client/) | Downloading and running the installer, shortcuts, the MES shortcut, copying an install, removing it |
| [Client settings](/classic/administration/client-settings/) | The `.sysconfig` file, sign-in mode, menu style, Kinetic versus Classic forms, desktop pop-ups from the System Monitor |
| [Classic client troubleshooting](/classic/administration/troubleshooting/) | Clearing the client cache, the `LogonDialog` constructor error, "An item with the same key has already been added" |

For the difference between the two clients and what they share, see [Kinetic vs Classic](/start/kinetic-vs-classic/).
